# CSI3210GroupC
A website for buying PC parts.

## Who it's for
People who want to replace parts in their PC or build a new one.

## What we wanted
- A clean website that's easy to read
- Fair prices
- Parts that are easy to find and compare

## Biases on the site
- Anchoring: some items show the old price crossed out
- Social proof: some items say how many students bought them
- Scarcity: some items say only a few are left

## How to run it
pip install -r requirements.txt
python app.py
Then go to http://127.0.0.1:5000
